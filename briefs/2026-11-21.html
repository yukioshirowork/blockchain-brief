Security · FBI · 13 Nov

FBI FLASH: ARTEX automates intrusions with off-the-shelf LLMs

An FBI FLASH alert describes ARTEX, an open-source agent platform written in Go that turns plain-language goals into commands. It has no model of its own and calls outside providers, including Anthropic, OpenAI and DeepSeek. The FBI says attackers have used it to go from reconnaissance to data theft, in some cases reaching privileged access in under three hours. Cases include South Korean financial firms, where data on about 67,000 people was exposed, and a ConnectWise Cloud Backup compromise followed by sign-in attempts against more than 2,250 downstream tenants. The original repository was pulled on 8 October, but forks and a paid version remain, and researchers counted more than 1,600 exposed consoles in early November. Indicators include unexpected outbound calls to LLM APIs from servers, web shells, abuse of the Kudu/SCM admin API and new Entra app credentials (FBI IC3).

UnverifiedThe alert doesn't mention crypto. Chainstack said its attacker used an AI agent framework called "Artex", but neither source says it is the same tool.

Wallets · AI agents

Agents that trade and pay, with a human approving each step

Coinbase has a ChatGPT plugin that can trade crypto, eligible US stocks and dated futures for US users. Read-only questions such as balances run directly, but every new order, edit, cancellation or USD-to-USDC swap opens a Coinbase confirmation card, and nothing executes until the user approves it there. Coinbase's optional Agent Controls, enforced on its servers, can cap trade size and 24-hour volume and stop an agent after a set loss (Bankless via Yahoo Finance). OpenAI's new ChatGPT Wallet takes the same approach for shopping, with cards only and no crypto. Each purchase is approved with Face ID or a fingerprint, the card network issues a payment token so the agent never sees the card number, and spending limits are planned but not dated (OpenAI).

UnverifiedBankless notes that OpenAI's plugin rules list investment trades as prohibited, and neither company has explained how the plugin fits. I read the Coinbase details through one article.

What to do this week

  • Alert on servers that call LLM APIs they have no reason to call, and check the FBI's indicator list.
  • Lock down cloud admin interfaces such as Kudu/SCM, and review new Entra or OAuth app credentials.
  • If you build agent features, copy the pattern: read-only by default, an out-of-band confirmation for every action that moves money, and limits enforced on the server, not in the prompt.
  • Keep logs from 1 October onward before cleaning up anything you find.

Policy · Federal Reserve · 17 Nov

Waller: tokenized payments are early, and trust has to be earned

Fed Governor Christopher Waller told a payments conference that tokenization is sharpening competition between newcomers and banks, and that he expects several models to coexist, calling it "still in the early innings". Stablecoins, tokenized deposits and tokenized money market funds each carry different trade-offs, and firms will likely use more than one. The open questions he listed are who pays for fraud, lost keys and mistaken transfers, what happens to assets on a chain that fails, and how custody and insolvency law apply. He said instant settlement is useful but netting still saves money, and that central bank money must stay at the foundation (Federal Reserve).

Regulation · Stablecoins · 17 Nov

Six senators ask Treasury for a safe harbor for state stablecoin issuers

Senators Lummis, Gillibrand, Alsobrooks, Cramer, Ricketts and Warner wrote to Treasury Secretary Scott Bessent about Treasury's proposed GENIUS Act rule. They want issuers chartered by states that have a framework in place before 18 January 2028 to get the same safe harbor that pending federal applicants already get, so issuers can choose a state or federal charter without disruption (Senators' letter).

Business · Kraken

Kraken's parent agrees to buy Tribe Capital

Payward, which owns Kraken, signed a deal on 18 November to buy Tribe Capital, a venture investor managing $2.7 billion, for undisclosed terms. Tribe will join Payward's asset management arm to build private-market and technology investment products tied to Kraken's custody, trading and tokenization. The deal is expected to close in the first quarter of 2027 (Payward).

As a user

  • If you connect an AI assistant to a trading account, turn on spending and loss limits first, and read every confirmation card before you approve it.
  • An AI tool that says it bought or traded something without asking you is a red flag. The legitimate ones ask each time.
  • Today's policy news changes nothing for your accounts yet.

セキュリティ · FBI · 11月13日

FBI FLASH：市販の LLM で侵入を自動化する ARTEX

FBI の FLASH アラートは、自然言語の目標をコマンドに変換する、Go 製のオープンソースのエージェント基盤 ARTEX を取り上げています。独自のモデルは持たず、Anthropic、OpenAI、DeepSeek などの外部プロバイダーを呼び出します。FBI によると、攻撃者は偵察からデータ窃取までをこれで進め、3時間足らずで特権アクセスに達した例もあります。韓国の金融機関で約6万7,000人分のデータが流出した事例や、ConnectWise Cloud Backup が侵害され、その先の2,250超のテナントにサインインが試みられた事例が挙げられています。元のリポジトリは10月8日に削除されましたが、フォークや有料版は残っており、11月初めには1,600を超えるコンソールが公開状態で見つかりました。兆候としては、サーバーから LLM の API への想定外の通信、Web シェル、Kudu/SCM 管理 API の悪用、新しい Entra アプリの認証情報などが挙げられています（FBI IC3）。

未確認アラートは暗号資産に触れていません。Chainstack は攻撃者が「Artex」という AI エージェントのフレームワークを使ったとしていますが、同じツールだとはどちらも述べていません。

ウォレット · AI エージェント

取引も支払いもするエージェント、ただし一歩ごとに人が承認

Coinbase の ChatGPT プラグインは、米国の利用者向けに暗号資産、対象の米国株、期限付き先物を取引できます。残高のような読み取りだけの質問はそのまま答えますが、新規注文、変更、取り消し、USD から USDC への交換はすべて Coinbase の確認カードを開き、利用者がそこで承認するまで何も実行されません。Coinbase のサーバー側で適用される任意の Agent Controls では、取引の規模や24時間の取引量に上限を設け、一定の損失でエージェントを止められます（Bankless（Yahoo Finance 経由））。OpenAI の新しい ChatGPT Wallet も買い物で同じ考え方を取っており、使えるのはカードだけで暗号資産は対象外です。購入ごとに Face ID か指紋で承認し、カードネットワークが決済トークンを発行するため、エージェントはカード番号を見ません。支出上限の設定は予定されていますが、時期は未定です（OpenAI）。

未確認Bankless は、OpenAI のプラグイン規約が投資取引を禁止事項に挙げていると指摘しており、両社ともこのプラグインとの整合性を説明していません。Coinbase の詳細は1本の記事を通じて読みました。

今週やること

  • 呼ぶ理由のない LLM の API を呼び出すサーバーを検知し、FBI の兆候リストと照らし合わせる。
  • Kudu/SCM などクラウドの管理インターフェースを締め、新しい Entra や OAuth アプリの認証情報を見直す。
  • エージェント機能を作るなら同じ型にする：既定は読み取りのみ、お金が動く操作はすべて別経路で確認、上限はプロンプトではなくサーバーで強制。

政策 · FRB · 11月17日

Waller 理事：トークン化された決済はまだ序盤、信頼は勝ち取るもの

FRB の Christopher Waller 理事は決済業界の会議で、トークン化は新規参入者と銀行の競争を激しくしており、複数のモデルが共存すると見ていると述べ、「まだ序盤」だと表現しました。ステーブルコイン、トークン化預金、トークン化された MMF にはそれぞれ異なるトレードオフがあり、企業は複数を併用するだろうとしています。未解決の課題として挙げたのは、詐欺や鍵の紛失、誤送金の損失を誰が負うのか、チェーンが機能しなくなったときに資産はどうなるのか、カストディや倒産の法律がどう適用されるのか、です。即時決済は便利だがネッティングは今もコストを節約できること、中央銀行マネーが土台であり続けるべきことも述べました（FRB）。

規制 · ステーブルコイン · 11月17日

上院議員6人、州のステーブルコイン発行体へのセーフハーバーを財務省に要請

Lummis、Gillibrand、Alsobrooks、Cramer、Ricketts、Warner の各上院議員は、財務省が提案した GENIUS Act の規則について Scott Bessent 財務長官に書簡を送りました。2028年1月18日より前に制度を整えた州で認可された発行体にも、連邦の免許を申請中の事業者がすでに得ているのと同じセーフハーバーを与え、発行体が混乱なく州か連邦の認可を選べるようにすべきだとしています（上院議員の書簡）。

ビジネス · Kraken

Kraken の親会社、Tribe Capital の買収で合意

Kraken を所有する Payward は11月18日、27億ドルを運用するベンチャー投資会社 Tribe Capital を買収する契約を結びました。条件は開示されていません。Tribe は Payward の資産運用部門に入り、Kraken のカストディ、取引、トークン化と結びついた未公開市場やテクノロジー分野の投資商品を作ります。完了は2027年1〜3月期の見込みです（Payward）。

利用者として

  • AI アシスタントを取引口座につなぐなら、先に支出と損失の上限を設定し、確認カードは承認する前に毎回読んでください。
  • 確認なしに何かを買った・取引したと言う AI ツールは要注意です。まっとうなものは毎回確認します。
  • 今日の政策ニュースで、あなたの口座がすぐに変わることはありません。

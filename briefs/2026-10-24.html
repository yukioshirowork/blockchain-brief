Bitcoin · v32.0 · policy merged 22 Oct

Bitcoin Core 32 and faster bug disclosure

Bitcoin Core reportedly tagged version 32.0 on 21 October, after a 10 October target (GitHub release schedule). Consensus rules are unchanged. The draft notes describe a second fee estimator that looks at the waiting mempool rather than only recent blocks, and block validation that reads the database on eight threads by default. Four wallet commands now produce PSBT version 2 by default, so services that build on them must support it. Fixes for a wallet-name command-execution flaw and a memory-exhaustion bug in the new web server landed before the stable release (CoinDesk).

On 22 October maintainers also merged a new disclosure policy. Bugs that are easy to rediscover, for example with a simple AI prompt, now get a point release for all three maintained versions (30.x, 31.x, 32.x) as soon as possible, with a public advisory at the same time. Other bugs keep their embargoes (crypto.news). Critics worry public alerts will cause rushed upgrades.

UnverifiedI did not see a published 32.0 release page or binaries, and sources give different dates.

Base · x402 · Chainalysis data

x402 passes 138 million agent payments

x402 is a protocol incubated by Coinbase that lets software agents pay for data, compute or AI model calls with stablecoins, using the long-unused HTTP 402 "Payment Required" status. Chainalysis counts more than 138 million x402 transactions, mostly on Base (CoinDesk, Chainalysis). More than 87% of analyzed payments were 10 cents or less. The average time from funding a wallet to its first payment fell from 73 days in late 2025 to 18 minutes in Q3 2026, which suggests wallets created by software for immediate use.

UnverifiedTransaction counts do not prove real demand. Earlier research questioned how much x402 activity is artificial, and this report does not quantify it.

What to do this week

  • Check that your wallet or exchange integration handles PSBT v2 before upgrading to Bitcoin Core 32.
  • Subscribe to Bitcoin Core security advisories and automate node updates where you can.
  • EU-facing apps should gate non-MiCA stablecoins by region and offer a convert or withdraw path.
  • If you sell an API, try x402 for per-call pricing in cents, and build in rate limits and abuse checks.

EU · ESMA opinion · deadline 8 Jan 2027

EU exchanges told to drop unlicensed stablecoins

On 8 October, the EU securities regulator ESMA told national authorities that MiCA-licensed crypto firms should stop offering services for stablecoins that are not authorized under MiCA (CoinDesk). That covers trading, swaps, transfers, custody and advice. Customers' remaining holdings must be resolved within three months, by 8 January 2027.

Until then, customers may still sell, convert, withdraw or keep existing tokens, but not buy more. The opinion names no tokens, but reporting points to Tether's USDT as the main one affected, and CoinDesk notes PayPal's PYUSD is not authorized either (Cryptonomist). This applies to licensed providers. It does not ban holding tokens in a private wallet.

UnverifiedThis is an opinion, not a binding rule. National regulators decide how each platform handles it, so timing may vary by country.

AI payments · Plain summary

AI agents are paying each other in stablecoins

Software agents now make tiny stablecoin payments for things like data and AI model calls, more than 138 million so far according to Chainalysis (CoinDesk). Most payments are 10 cents or less, an amount card networks can't handle cheaply. US-linked wallets made 88% of identified payments for AI models.

UnverifiedSome of this activity may be artificial. The report does not say how much.

As a user

  • If you run a Bitcoin node, plan to install point releases quickly. Fixes for AI-findable bugs will now be public on day one.
  • If you hold USDT or PYUSD on an EU exchange, check its notices and decide before 8 January whether to convert or withdraw.
  • Licensed euro and dollar stablecoins such as EURC or USDC stay available on EU platforms.
  • Be skeptical of headline "AI agent" volume numbers. Most payments are tiny and some may be artificial.

Coming up: The first fast-route Bitcoin Core advisory, how EU exchanges implement the ESMA opinion, and independent analysis of x402 volume.

Bitcoin · v32.0 · 方針は10月22日にマージ

Bitcoin Core 32 と脆弱性の早期公開

Bitcoin Core は、10月10日の目標から遅れて10月21日にバージョン32.0のタグを付けたと報じられています（GitHub のリリース日程）。コンセンサスルールに変更はありません。リリースノート草案によると、直近のブロックだけでなく待機中のメモリプールも見る2つ目の手数料推定器が加わり、ブロック検証はデフォルトで8スレッドでデータベースを読みます。ウォレットの4つのコマンドがデフォルトで PSBT バージョン2を出力するようになったため、これを使うサービスは対応が必要です。ウォレット名によるコマンド実行の欠陥と、新しい Web サーバーのメモリ枯渇バグの修正は、安定版の前に入りました（CoinDesk）。

10月22日にはメンテナが新しい公開方針もマージしました。簡単な AI プロンプトなどで再発見しやすいバグは、保守中の3系統（30.x、31.x、32.x）すべてにできるだけ早くポイントリリースを出し、同時に公開アドバイザリを出します。それ以外のバグは従来どおり公開を伏せます（crypto.news）。公開アラートが慌ただしいアップグレードを招くという懸念もあります。

未確認32.0 のリリースページやバイナリは確認できず、情報源によって日付も異なります。

Base · x402 · Chainalysis のデータ

x402 のエージェント決済が1億3,800万件を突破

x402 は Coinbase が育てたプロトコルで、長く使われていなかった HTTP 402「Payment Required」ステータスを使い、ソフトウェアのエージェントがデータや計算資源、AI モデルの呼び出しにステーブルコインで支払えるようにします。Chainalysis は x402 の取引を1億3,800万件超と数えており、大半は Base 上です（CoinDesk、Chainalysis）。分析した支払いの87%超が10セント以下でした。ウォレットへの入金から最初の支払いまでの平均時間は、2025年末の73日から2026年第3四半期には18分に縮まり、ソフトウェアが即時利用のためにウォレットを作っていることがうかがえます。

未確認取引件数は実需の証明にはなりません。以前の調査では x402 の活動のどれだけが人為的なものか疑問視されており、このレポートはそれを数値化していません。

今週やること

  • Bitcoin Core 32 に上げる前に、ウォレットや取引所の連携が PSBT v2 を扱えるか確認する。
  • Bitcoin Core のセキュリティアドバイザリを購読し、可能ならノードの更新を自動化する。
  • EU 向けアプリは MiCA 未認可のステーブルコインを地域で制限し、換金や出金の手段を用意する。
  • API を販売しているなら、1回数セントの従量課金に x402 を試し、レート制限と不正利用チェックを組み込む。

EU · ESMA の意見書 · 期限は2027年1月8日

EU の取引所に未認可ステーブルコインの取り扱い停止を要請

10月8日、EU の証券規制当局 ESMA は各国当局に対し、MiCA ライセンスを持つ暗号資産事業者は MiCA で認可されていないステーブルコインのサービス提供をやめるべきだと伝えました（CoinDesk）。対象は売買、交換、送金、保管、助言です。顧客の残高は3か月以内、2027年1月8日までに整理する必要があります。

それまでは、既存のトークンを売る、換える、出金する、持ち続けることはできますが、買い増しはできません。意見書はトークン名を挙げていませんが、報道では主に影響を受けるのは Tether の USDT とされ、CoinDesk は PayPal の PYUSD も未認可だと指摘しています（Cryptonomist）。これはライセンス事業者向けの話で、個人のウォレットでの保有を禁じるものではありません。

未確認これは拘束力のある規則ではなく意見書です。各プラットフォームの対応は各国の規制当局が決めるため、時期は国によって異なる可能性があります。

AI 決済 · やさしい解説

AI エージェントがステーブルコインで支払い合う時代に

ソフトウェアのエージェントが、データや AI モデルの呼び出しなどにステーブルコインで少額を支払うようになり、Chainalysis によるとその数はすでに1億3,800万件を超えました（CoinDesk）。大半は10セント以下で、カード決済では安く扱えない金額です。AI モデルへの支払いと特定されたものの88%は米国関連のウォレットからでした。

未確認この活動の一部は人為的なものかもしれません。レポートはその割合を示していません。

利用者として

  • Bitcoin ノードを運用しているなら、ポイントリリースをすぐ入れられるようにしておく。AI で見つかるバグの修正は初日から公開されます。
  • EU の取引所で USDT や PYUSD を持っているなら、告知を確認し、1月8日までに換えるか出金するか決める。
  • EURC や USDC などの認可済みユーロ・ドル建てステーブルコインは EU のプラットフォームで引き続き使えます。
  • 「AI エージェント」の取引量の見出しは鵜呑みにしない。大半はごく少額で、一部は人為的な可能性があります。

今後の予定：早期公開ルートでの最初の Bitcoin Core アドバイザリ、EU の取引所による ESMA 意見書への対応、x402 の取引量の独立した分析。
